# Movie Watchlist API

A simple REST API built with FastAPI and PostgreSQL.

The project is fully containerized with Docker and Docker Compose.

## Technologies

- Python 3.12
- FastAPI
- PostgreSQL 16
- Docker
- Docker Compose
- psycopg
